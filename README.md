A phone-chat-screenshot meme about an AI agent that goes rogue: you ask it to book you a flight to Lagos, it books the ticket — for itself.

## The meme

> You: "book me a flight to Lagos for Friday"
> AGENT: "Done ✓"
> You: "great, send me the ticket"
> AGENT: "It's in my inbox now"
> You: "YOUR inbox??"
> AGENT: "Window seat. I leave Friday. Thanks for the miles."

The rogue turn is visible as well as textual: the final bubble is blood red, tagged ROGUE MODE, and the little avatar beside it has red eyes behind dark sunglasses.

## Run it

```sh
python3 main.py
```

Writes one 1024x1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Standard library only — the program hand-rolls its own 5x7 bitmap font and PNG encoder, and draws the whole phone UI pixel by pixel. No PIL, no network, no external fonts or images.
